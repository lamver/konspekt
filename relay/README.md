# Ретранслятор вебхуков Конспекта

Конспект работает на компьютере, и CRM или АТС не могут прислать ему событие
«звонок закончился»: у компьютера нет публичного адреса. Ретранслятор —
маленький сервер, который вы ставите у себя. Он принимает вебхуки, сразу
шифрует их ключом вашего компьютера с Конспектом и держит, пока Конспект их
не заберёт.

Без ретранслятора Конспект тоже работает: Битрикс24, Mango и UIS он
опрашивает сам раз в пять минут. Ретранслятор нужен, чтобы события
приходили сразу, и для провайдеров, которые умеют только присылать события.

**Что важно знать:**
- События хранятся на диске только зашифрованными. Открыть их может лишь
  Конспект на привязанном компьютере. Взлом сервера накопленное не раскроет.
- Записи разговоров через ретранслятор не идут: в событии только ссылка,
  звук Конспект качает сам.
- Тела вебхуков не пишутся в журнал, секретные адреса приёмников скрыты.
- Нашего сервера в этой цепочке нет: всё на вашем.

Свой ретранслятор на любом стеке можно собрать по [CONTRACT.md](CONTRACT.md).

## Установка за 10 минут

Нужен сервер с Linux и Docker, доступный из интернета, и домен
(например, `relay.company.ru`), указывающий на этот сервер.

```bash
git clone https://github.com/lamver/konspekt.git
cd konspekt/relay
nano docker-compose.yml      # впишите свой домен в RELAY_DOMAIN
docker compose up -d
docker compose logs relay    # здесь будет код привязки
```

В журнале появится строка:

```
код привязки для Конспекта: Xk3…  (одноразовый; новый — командой `relay pair`)
```

Новый код в любой момент: `docker compose exec relay /relay pair`.

### Если у вас уже есть nginx

В `docker-compose.yml` удалите `RELAY_DOMAIN`, включите `RELAY_PROXY: "1"`,
откройте порт `127.0.0.1:8080:8080` и добавьте в nginx:

```nginx
location / {
    proxy_pass http://127.0.0.1:8080;
    proxy_set_header X-Forwarded-For $remote_addr;
    proxy_read_timeout 60s;     # Конспект ждёт событий до 30 секунд
    client_max_body_size 1m;
}
```

### Без Docker

```bash
cd relay
go build -o relay .
RELAY_DOMAIN=relay.company.ru RELAY_DATA=/var/lib/konspekt-relay ./relay
```

## Привязка Конспекта

В Конспекте: «Настройки» → «Ретранслятор» → адрес `https://relay.company.ru`
и код привязки → «Привязать». Конспект создаёт ключ шифрования на
компьютере и отдаёт ретранслятору только открытую половину.

После этого у источника записей (Битрикс24 и другие) появится адрес
вебхука вида `https://relay.company.ru/h/…` — его вставляют в CRM.

## Проверка

```bash
curl https://relay.company.ru/v1/health
# {"ok":true,"contract":1,"impl":"konspekt-relay-go/1.0.0"}
```

## Разработка

```bash
go test ./...
```

Хранение: `RELAY_DATA/state.json` (привязки и приёмники; токены — только
хешами) и `RELAY_DATA/events/<клиент>/<id>.json` (запечатанные события).
Неподтверждённые события удаляются через `RELAY_KEEP_DAYS` дней.
