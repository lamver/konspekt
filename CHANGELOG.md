# Изменения

Все заметные изменения Konspekt. Записи на человеческом языке: что теперь
можно делать, а не какие файлы тронуты. Формат по мотивам
[Keep a Changelog](https://keepachangelog.com/ru/1.1.0/), версии по
[семантическому версионированию](https://semver.org/lang/ru/).

Правило работы: каждая законченная порция работы попадает сюда в разделе
«Не выпущено» тем же коммитом, что и сам код.

## Не выпущено

### Изменено

- Проверки разделены на быстрые и медленные: быстрые гоняются на каждый
  push, тяжёлые с моделями по ночам, поэтому обычный коммит проверяется
  за минуты, а не за полчаса (`af38bd7`, `dab3930`)
- Проверки в облаке перестали жечь минуты впустую: установщик собирается
  только на тег или по кнопке, тяжёлые тесты раз в неделю, а новый push
  отменяет предыдущий прогон той же ветки

### Исправлено

- Пересборка значка больше не падает на русском выводе в консоли Windows
- Быстрые тесты снова проходят локально: русский вывод ронял их в консоли
  Windows, хотя проверки были успешными

## 0.4.0 — Синтез заметок и первая сборка, 2026-08-31

Первый публичный билд: приложение ставится на машину без Python, а
заметки собирает локальная модель.

### Добавлено

- Проверка новых версий: приложение раз в сутки смотрит `latest.json` в
  публичном репозитории релизов и сообщает о свежей сборке. Проверку
  можно отключить (`e93b263`)
- Сборка и релиз в GitHub Actions: тег запускает сборку установщика и
  публикацию (`bc2c43b`)
- Установщик Inno Setup, значок приложения и номер версии в сборке
  (`f216af6`)
- Сборка приложения PyInstaller папкой: запускается на машине без
  Python (`21dc8e9`)
- Саммари встречи и чат по встрече прямо в окне, длинные встречи
  разбираются по смыслу кусками (`bc1be69`, `a0e2eb5`)
- Клиент LLM в формате OpenAI, промпты и запуск локальной модели через
  llama.cpp (`c8f2641`)
- История чата по встрече в базе, схема 4 (`7014cb9`)
- Модель скачивается при первом запросе, а не при установке (`fc02852`)
- Ход разбора виден в шапке саммари, занятость привязана к встрече
  (`0584bfb`)
- Свои шрифты и боковая колонка, которую можно тянуть (`5a6f772`)

### Исправлено

- Приложение снова запускается: правка проверки версий случайно стёрла
  заголовок метода сборки распознавателя (`52558e7`)
- Проверка обновлений больше не стучится в приватный репозиторий по
  токену, которого в сборке нет (`52558e7`)
- Текст встречи снова выделяется и копируется мышью (`1600ad6`)

### Решения

- Модель монетизации, открытость кода и защита лицензии, позиционирование
  на четырёх языках, лицензии моделей и файл NOTICE. Подробности в
  `docs/tasks/` и `docs/licenses.md`
