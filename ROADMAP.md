# Konspekt — умный блокнот для встреч

Локальный аналог Granola с упором на русский язык (GigaAM) и приватность.

## Принципы

1. **Максимально просто сейчас, расширяемо потом.** Каждая тяжёлая подсистема
   (захват звука, ASR, LLM-синтез) прячется за узким протоколом. В MVP —
   заглушка, дальше подменяется реализацией без правок UI.
2. **Локально по умолчанию.** Аудио и транскрипт не покидают машину, пока
   пользователь явно не включил облачный провайдер.
3. **Целимся в ONNX, а не в torch.** Даже если первый прототип на чём-то
   другом — интерфейс ASR обязан быть совместим с ONNX-рантаймом, иначе
   потом не отдерём зависимости и не соберём бинарник.

## Архитектура

```
konspekt/
  app/
    core/        события, конфиг, модели данных, шина
    audio/       захват: микрофон + WASAPI loopback  (этап 2)
    asr/         Transcriber: GigaAM ONNX | Whisper | Null  (этап 3)
    notes/       синтез заметок, шаблоны встреч  (этап 4)
    storage/     SQLite + файлы аудио
    ui/          pywebview окно + веб-фронт
    tray/        иконка в трее, горячие клавиши
  web/           статика фронта (HTML/CSS/JS, без сборки)
  models/        скачанные веса (в .gitignore)
```

Бэкенд и фронт общаются через JS-мост pywebview (`window.pywebview.api`)
плюс события сервер→клиент. HTTP-сервер не поднимаем: лишний порт, лишний
файрвол-попап, лишняя поверхность атаки.

## Этапы

### Этап 1 — Оболочка (готово)

Цель: окно поверх остальных, прячется в трей, визуально близко к Granola.
Звука и AI ещё нет — вместо них заглушки, но с настоящими интерфейсами.

- [x] Каркас проекта: `uv`, Python 3.12, зависимости, запуск одной командой
- [x] Окно pywebview: frameless, always-on-top, перетаскиваемое, запоминает
      позицию и размер
- [x] Трей (pystray): показать/скрыть, «Новая встреча», выход. Закрытие окна
      сворачивает в трей, а не завершает приложение
- [x] Глобальная горячая клавиша показать/скрыть
- [x] UI: список встреч слева, редактор заметок справа, панель записи сверху,
      таймер, кнопка старт/стоп
- [x] Редактор заметок с таймстемпами: каждая строка помнит момент встречи
- [x] Хранилище SQLite: встречи, заметки, (заготовка) сегменты транскрипта
- [x] Заглушки `AudioCapture` и `Transcriber`, отдающие фейковые данные,
      чтобы весь UI-поток проверялся целиком

### Этап 2 — Звук (готово)

- [x] Микрофон + WASAPI loopback раздельными дорожками (`soundcard`),
      сохранение в WAV 16 кГц моно
- [x] Индикатор уровня по реальному сигналу, выбор устройств в UI
- [x] Нарезка на чанки для распознавания (готовый вход для этапа 3)
- [ ] VAD: отбрасывать тишину, чтобы не гонять её через ASR

### Этап 3 — Распознавание (готово)

- [x] GigaAM v3 CTC в ONNX через `onnx-asr`: только numpy и onnxruntime,
      без torch и NeMo. Веса int8, 214 МБ вместо 885 МБ у fp32
- [x] Скачивание модели прямо из приложения: прогресс, отмена, докачка
      после обрыва связи (проверено на настоящем разрыве)
- [x] Очередь распознавания в фоновом потоке: захват не ждёт модель,
      переполнение отбрасывает старое вместо роста памяти
- [x] Живой транскрипт в UI: реплики «я» и «собеседник» разделены по
      источнику звука, а не диаризацией, поэтому разделение точное
- [x] Поиск речи: тишина не попадает в модель, а фразы режутся по паузам,
      а не по границе куска. Порог считается от текущего фона, поэтому
      работает и на тихом микрофоне, и при гуле
- [x] GigaAM e2e вместо обычного CTC: пунктуация, заглавные буквы и числа
      цифрами при том же весе и той же скорости
- [x] Роутер языка: русский → GigaAM, остальное → Whisper base int8.
      Язык определяется по звуку (VoxLingua107), а не по тексту: текст к
      этому моменту уже испорчен кириллицей
- [x] Диаризация внутри дорожки: WeSpeaker ResNet34, 26 МБ ONNX. Работает
      и для нескольких собеседников в звонке, и для нескольких человек
      за одним компьютером

### Этап 3.5 — Кто говорит и на каком языке (готово)

- [x] Ресайз frameless-окна за края и углы с запоминанием размера
- [x] Темы: светлая, тёмная, системная
- [x] Запуск двойным щелчком: `konspekt.bat` без окна консоли
- [x] Имена говорящих в транскрипте, правка по клику на подпись
- [x] Голоса запоминаются между встречами: назвал человека один раз, и на
      следующих встречах он определяется сам
- [x] Эталон голоса владельца: читаешь пару фраз, и программа отличает
      тебя от остальных даже в общей дорожке микрофона

Что осталось на потом:

- [ ] Разделение говорящих при перекрытии: если двое говорят
      одновременно, их голоса уже смешаны в одном сигнале, и эмбеддер
      разделить их не может. Это предел записи, а не модели
- [ ] Whisper small вместо base, если качество коротких английских фраз
      окажется недостаточным

### Этап 4 — Синтез заметок

- Промпт «мои тезисы + транскрипт → развёрнутое саммари»
- Шаблоны встреч: 1:1, продажи, стендап, интервью
- Провайдеры: локальная LLM / GigaChat / OpenAI, за одним интерфейсом

### Этап 5 — Дистрибуция

- PyInstaller через GitHub Actions, матрица windows/macos/linux
- Автообновление, подпись кода
