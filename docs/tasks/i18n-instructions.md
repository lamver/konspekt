## Что делать: Этап 6, GitHub issue #2 — «Локализация интерфейса: ru, en, es, sr»

### Языки
Русский (оригинал), английский, испанский, сербский (только латиница,
кириллица откладывается на потом).

### Объём
Строки лежат в трёх местах:
- `web/index.html` — ~67 строк (заголовки, кнопки, плейсхолдеры,
  подсказки в настройках)
- `web/app.js` — ~50 строк (сообщения, тексты, вставляемые по месту)
- `app/**/*.py` — ~30 сообщений для пользователя. **Не логи** — логи
  остаются русскими навсегда, их читают разработчики, не пользователи.

Итого около 150 фраз.

### Задачи по порядку

1. **Инвентаризация.** Выписать каждую фразу с осмысленным ключом
   (`sidebar.new_meeting`, а не `новая_встреча`) в файл
   `docs/tasks/i18n-inventory.md`: файл → строка → ключ → текст.
   Сделать это первым шагом, до перевода.

2. **Механизм i18n:**
   - JSON-файлы с переводами: `web/i18n/ru.json`, `en.json`,
     `es.json`, `sr.json`
   - Функция `t(key)` в `app.js`, достающая строку по текущему языку
   - В `index.html` заменить хардкод на `data-i18n="sidebar.new_meeting"`
     и функцию, которая на старте проходит по DOM и подставляет переводы
   - Для питона (`app/**/*.py`) — отдельный словарь сообщений,
     доступный из `Api` (`app/ui/api.py`), с той же системой ключей

3. **Выбор языка интерфейса** — добавить в настройки, раздел
   «Оформление», рядом с темой. Хранить выбор в `settings.json`
   (смотри `app/core/settings.py`).

4. **Перевод** — аккуратный, по смыслу, не гугл-транслейт. Стиль
   проекта: короткие человеческие формулировки, без канцелярита.
   Испанский — нейтральный (не мексиканский и не кастильский
   специфично). Сербский — литературная латиница.

### Важно не путать

Язык интерфейса и язык распознаваемой речи — **разные вещи**.
Распознавание уже двуязычное: русская речь идёт в GigaAM, остальная
в Whisper, определяет VoxLingua. Смена языка интерфейса на английский
не должна ничего менять в распознавании: человек может работать в
английском интерфейсе и записывать русские встречи.

**Не трогать `app/asr/*` вообще.**
