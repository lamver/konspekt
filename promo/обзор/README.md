# Обзорный ролик Конспекта

Ролик на минуту с небольшим: запись, расшифровка, итоги, чат, разборы,
поиск, источники звонков, диктовка, четыре языка, приватность. Картинка —
настоящие снимки программы, сверху титры, под ними озвучка и мягкие
ASMR-акценты. 1920×1080, 30 кадров в секунду.

## Из чего собран

| Файл | Что в нём | Меняется при переводе |
|---|---|---|
| `сценарий.js` | порядок сцен, снимки, точки наезда, ASMR-акценты | нет |
| `тексты/<язык>.js` | титры и текст озвучки | да, это и есть перевод |
| `../голос/<язык>/vo-NN.wav` | реплики озвучки, по файлу на сцену | да |
| `../../docs/screenshots/<язык>/` | снимки программы | снимает `tools/снимки_инструкции.py` |
| `ролик.html` | как рисовать сцены | нет |
| `собрать.py` | тайминги, сведение звука, кадры, mp4 | нет |
| `сборка/<язык>/голос.js` | длины реплик; пишет `собрать.py` | сам |

Длина сцен не задана руками: каждая сцена длится столько, сколько её
реплика, плюс вход и хвост (`голос_вход`, `голос_хвост` в сценарии),
но не короче `мин`. Поэтому перевод с более длинными фразами ничего не
ломает: сцены сами растянутся.

## Собрать

```bash
python promo/обзор/собрать.py en
```

Нужны Python из `.venv`, Node, Chrome или Edge и ffmpeg. Результат —
`promo/out/konspekt-обзор-en.mp4`. Посмотреть без сборки: собрать
тайминги (`--без-видео`) и открыть `promo/обзор/ролик.html?язык=en`
в браузере.

## Сделать на другом языке

1. Снимки: `python tools/снимки_инструкции.py es` (уже есть для ru, en, es, sr).
2. Тексты: скопировать `тексты/en.js` в `тексты/es.js`, перевести значения,
   ключи не трогать. `*звёздочки*` выделяют слово цветом.
3. Озвучка: по реплике на сцену, номера из поля `голос` в сценарии,
   в `promo/голос/es/vo-01.wav` и далее. Текст реплик — поле `голос` в
   текстах. Тишину по краям `собрать.py` срежет сам.
4. `python promo/обзор/собрать.py es`.

Пока озвучки нет, ролик собирается и так: длина сцены прикидывается по
числу слов реплики.

## Добавить или убрать сцену

Сцена — запись в `сценарий.js` и одноимённый ключ в каждом
`тексты/<язык>.js`. Виды сцен: `вступление`, `снимок`, `снимки`
(несколько снимков по очереди), `языки` (сетка из четырёх снимков),
`финал`. Точка наезда `[x, y, масштаб]` — в пикселях снимка 1044×721:
эта точка остаётся на месте, а снимок увеличивается вокруг неё.

## Что не обещаем в ролике

Цены и адреса сайта в ролике нет (решение 03.10): ролик живёт дольше
цен, а адрес у каждого рынка свой. В финале только «AI.TECH».
